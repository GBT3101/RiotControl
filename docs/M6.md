# M6 — Simulation core

Headless, deterministic, fixed-step (30 Hz) simulation in `src/sim/`, driven by data tables in
`src/data/`. No DOM/Pixi imports; it runs in Node (tests, headless bots) and in the browser.

## Architecture

- **Coordinates**: continuous tile space (u = `x`, v = `y`); tile (i, j) covers [i, i+1)×[j, j+1).
  Convert with `core/iso.tileToWorld`. Distances in tiles, times in seconds.
- **Determinism**: only `world.rng` (seeded `Rng.fork('sim')`), no `Math.random`/`Date`, fixed
  iteration orders, Dijkstra heap tie-broken by tile index. Same seed + same commands at the
  same ticks → identical `stateHash()` (tested over 60 s with combat & waves). Trig is avoided
  in the hot paths (only `Math.cos` of a constant cone angle and `Math.pow` in the wave curve),
  so cross-engine replays are very likely but only same-engine determinism is guaranteed.
- **Step order**: prev positions → director (spawns) → flow field (throttled) → spatial hash +
  unit grid → roof guards (every 15 ticks) → units (statuses + behaviour) → crowd → projectiles
  → areas → bodies → Capitol. After victory/defeat `step()` is a no-op.
- **Crowd**: SoA typed arrays, capacity 4096 (configurable ≤ 65536), free-list keeps slots compact,
  `hi` bounds loops. Handle = `slot | gen << 16` (`crowd.handle/resolve`), plus a never-reused `uid`.
- **Navigation**: flow field from the Capitol steps using `GROUND_COST`; blockade tiles are
  movement-solid but passable in the field at +30 cost (crowds detour if cheap, otherwise press
  and jam against them); stationary units add +3 so crowds flow around them. Recompute when
  dirty, at most every 0.5 s (≈0.8 ms on 72×72). Steering: bilinear flow sample + slow lateral
  weave (spreads hordes over wide roads) + separation (≤14 neighbours via the hash) + wall band
  + slide-along-wall collision + push-out of unit circles.
- **Engagement**: units expose `meleeSlots` (`holders`); stationary units *recruit* marching
  protesters within `engageRadius` (1.3 tiles) into free slots — they walk up and fight; surplus
  protesters flow past. Blockades hold 4 per tile by contact. Moving commandables release holders.
- **Combat**: per-source `lethal` flag (baton/rubber/gas = KO, guns/explosions/fire/crush = lethal);
  armour per damage type; hitscan shots emit `fired` tracers; ballistic shots are projectiles
  with parabolic `z`; tank shells hurt own ground units (`friendlyFire`, min range 2.8 so it never
  shells itself); Prophets explode on contact (tank: 50% max HP); statuses: stun, blind, gas DoT
  (`gasT`, 10 HP/s), burning (`burnT`).
- **Performance**: no per-protester allocation; scratch typed arrays at module level. Measured:
  **3000 protesters + 60 fighting units: 2.25–2.55 ms/tick avg in Node** (`tests/sim-perf`);
  normal play ~0.3–0.5 ms/tick (headless 40-min run, peak 1300 crowd).

## API for the view (M8)

```ts
const w = new World(map, { seed, quality: 'desktop' });   // loop.update → w.step()
// each rendered frame:
for (const e of w.events.drain()) …                         // or dispatchEvents(batch, bus)
```
- **Protesters** (`w.crowd`, iterate `s < crowd.hi` where `alive[s]`): `uid`/`handle(s)`,
  `type` (`PT`), `variant` (paper-doll seed), `loadout`, `x,y` + `px,py` (lerp with `loop.alpha`),
  `facing` (0 se, 1 sw, 2 ne, 3 nw = `FACINGS`), `anim` (`PANIM`: IDLE WALK RUN ATTACK SHOOT THROW
  CLIMB ROOF STUNNED RIOT COUGH), `state` (`PS`), `hp/maxHp`, `lastAtk` (sim time of last hit —
  sync impact frames), `stun`, `gasT`, `burnT`, `climb` (0..1 facade progress; height =
  climb × storeys of building `bld`), `gx,gy` (climb point).
- **Units** (`w.units.active`): `id`, `type`, `def`, `x,y,px,py`, `z` (storeys: roof height / heli
  altitude `HELI_ALTITUDE`), `state` (`US`), `facing`, `dir8`/`aim8` (vehicles/turrets: 0 E,
  1 SE, 2 S, 3 SW, 4 W, 5 NW, 6 N, 7 NE screen octants), `aimX/aimY` (gas spray), `hp/maxHp`,
  `members` (brigade), `damageState` (blockade 0/1/2), `tiles` (blockade), `building`,
  `lastAttack`, `lastHurt`, `abilityReady`, `charge/def.ability.charge`, `moving`, `path`.
- **Projectiles** (`w.projectiles.active`): `id, kind ('shell'|'bazooka'|'molotov'|'gasGrenade'),
  x, y, z, x0..y1, t/dur`. **Areas** (`w.areas.active`): `id, kind ('gas'|'fire'), x, y, r, ttl/dur`.
- **Bodies** (`w.bodies`, SoA ring, iterate `k < capacity` where `alive[k]`): `id, x, y, kind`
  (`BODY_KIND`), `type` (protester type / unit index), `variant`, `lethal`, `facing`, `ttl`,
  `trample` (crowd overlap counter), `cause`.
- **Capitol**: `w.capitol.integrity` (0..1), `.state` (0 pristine … 5 collapsing), `.attackers`.
- **Economy/director**: `w.hate`, `w.legit`, `w.level`, `w.progress`, `w.director.{phase, wave,
  waveSize, pending, breather, breatherTotal}`, `w.phase` ('playing'|'victory'|'defeat'), `w.stats`.
- **Events** (`SimEventMap` in `sim/events.ts`, each with `type` + `tick`): `spawned` (door i/j,
  building), `unitDeployed`, `commanded`, `died` {cause, lethal, bodyId, by}, `unitDied` {member,
  squadLeft, thrownOff}, `attacked` {attacker/target kind+id, damage, dmgType}, `fired` {weapon,
  x0,y0,z0 → x1,y1, projectileId (-1 = hitscan tracer)}, `exploded`, `areaCreated`, `thrownOffRoof`
  {from, height, to}, `climbStart`, `reachedRoof`, `abilityReady`, `abilityUsed`, `flash`,
  `bretaSpawned`, `levelUp` {units, protesters}, `waveStart`, `waveEnd`, `capitolDamaged`
  (aggregated ≤ 1/s), `capitolState`, `hateGained` {amount, pos, reason}, `hateSpent`,
  `legitGained`, `defeat`/`victory` {stats ledger}.

## API for the UI (M9)

| Call | Returns |
|---|---|
| `w.canDeploy(unit, i, j)` | `DeployCheck {ok, reason, cost, tiles (ghost; blockade snaps ≤3 across the road), building, x, y}`; reasons `phase locked hate bounds notRoad occupied notRooftop roofTaken` |
| `w.deploy(unit, i, j)` | `Unit \| null` (spends Hate) |
| `w.command(unitId, i, j)` | `boolean` — commandables; road-only A* (heli: anywhere) |
| `w.useAbility(unitId)` / `w.useAllAbilities()` | gas grenade at the densest crowd in range (G hotkey) |
| `w.startWaves()` | leave the untimed prep phase ("Let them come") |
| `w.callNextWaveEarly()` | bonus Hate (= breather seconds left / 2), 0 if not in a breather |
| pause / speed | external: `FixedStepLoop.paused` / `timeScale` |

## Headless runner

```sh
node --input-type=module -e "const {runnerImport}=await import('vite');
  const {module:m}=await runnerImport('./src/sim/headless.ts',{configFile:false,logLevel:'error'});
  await m.main(process.argv.slice(1))" -- --seconds 900 --seed 3 --bot escalate
```
Bots: `none`, `riot` (riot lines + some snipers/blockades/gas), `escalate` (best affordable).
Example (escalate, 2400 s): wave 31, level 10, legit 4990, 80 890 protesters fallen, 221 officers
lost, peak crowd 1300, avg 0.46 ms/tick. A `tools/sim.mjs` wrapper would be a nice shared addition.

## Known gaps / for M7 & M12

- Balance is untuned (M12): the escalate bot reaches ~5000 Legit in ~40 min, the riot bot faster;
  Capitol HP (5000) and per-type Capitol DPS are chosen values (brief gives student "1").
- District `rally` points are not used yet (protesters mill at the door, then march straight).
- Rooftop units don't fight back against climbers; climbers on a roof just hit the unit.
- Helicopter has no altitude-based targeting rules; rooftop units shoot from the footprint centre.
- Commandable ground units don't avoid each other; one stationary ground unit per tile only for
  deployment.
- Protesters stay in `ENGAGED` with blockades by contact; no "climb over / squeeze through" logic.
- Occasional tick spikes (≤ ~20 ms in a 40-min run) from GC / flow recomputes; consider spreading
  the Dijkstra over ticks in M13 if it shows up in frame pacing.
