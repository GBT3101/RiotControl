# Special skills (owner request, playtest round 2)

The owner loves the Tear Gas Shooter's grenade (charge → pulsing cue over the unit and a THROW button in the info
panel → tap → thrown). Five more units get a special skill on the same model. **The higher the unit's level, the
longer the skill takes to charge.**

Rules for every skill:

- Charging pauses while the unit is stunned or knocked down; the charge ring and the "ready" cue reuse the gas pattern (ring in the info panel + bouncing cue icon over the unit in the world; each skill has its own icon).
- Skills never hurt the player's own units (the satire lives elsewhere).
- Kills from skills follow the normal Hate rules (1 per 3 protesters, Breta +100).
- Deterministic sim: skill effects resolve in the fixed-step sim from a player command; the view only animates events.
- Mobile first: the aim and paint modes must work with one thumb, show what will happen before it happens, and never fire by accident (a pan/zoom gesture does not fire).
- Bots use the skills, so `npm run playtest` exercises them.
- Tuning numbers (charge, radius, damage) live in `src/data/units.ts` `ability` and may be tuned by playtests; the owner-set
  costs and Legitimacy may not.
