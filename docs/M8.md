# M8 — Integration: world view & game feel

M8 binds the deterministic simulation (M6/M7, `src/sim`) to Pixi and wraps both in a
`GameController` that M9 (UI/HUD/screens), M10 (tutorial) and M11 (audio) build on.
`index.html` boots straight into a run (`?city=madrid|london|paris`); `?demo=1` keeps the M1
test-map scene.

```
main.ts → game/boot.ts
  createPixelStage → LoadingScreen → critical art (workers) → World → GameController → first frame
                                                             └→ deferred art (2 background stages)
GameController ── world (sim) · FixedStepLoop (30 Hz) · Camera + CameraController · WorldView · bus
WorldView ── TerrainView · StaticView · ProtesterView · UnitView · BodyView · CombatView
             AmbientView · FxSystem · DecalLayer · OverlayView · Juice
```

## 2. Layers (`view/layers.ts`)

Bottom → top, all inside the `world` render group (camera transform + integer shake) except
`screen`:

| Layer                        | Contents                                                                                                                                                                  | Grade            |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| `terrain`                    | worker-baked 16×16-tile ground chunks (water chunks: 4 frames)                                                                                                            | container tint   |
| `decals`                     | map-sized decal render texture (blood, scorch, rubble), cast shadows                                                                                                      | container tint   |
| `bodies`                     | fallen bodies, dying anims, ground FX (shockwaves, trample dust)                                                                                                          | container tint   |
| `marks`                      | ground UI: deploy tile highlights, range ring, selection ring of ground units                                                                                             | never            |
| `entities`                   | buildings (depth pieces), props, people, vehicles, upright FX, gas puffs, waypoint flag, placement ghost, roof highlights, rooftop selection rings — **sorted by zIndex** | per sprite       |
| `ghostsEnemy` / `ghostsAlly` | x-ray silhouettes of people fully hidden behind buildings                                                                                                                 | flat team colour |
| `air`                        | helicopters, thrown snipers, projectiles, tracers (sorted)                                                                                                                | per sprite       |
| `lights`                     | additive light sprites: lamp pools, halos, fire glows, muzzle flashes, sirens, blasts                                                                                     | alpha ∝ darkness |
| `overlays`                   | always-on-top world UI: Legitimacy seals, the placement ghost when it is behind a building                                                                                | never            |
| `screen`                     | screen-space FX at UI scale: Hate fists flying to the HUD, level-up confetti                                                                                              | never            |

## 3. Depth sorting (`view/depth.ts`)

- Entities sort by `depthKey(x, y)` of their ground point (world px; foot y then x).
- Buildings, the Capitol and landmarks are split at art-load time into square sub-boxes
  (`g = gcd(w, d)`); each screen column of pixels is assigned to the **front** sub-box covering it
  (`footprintAssignment`, H = ∞) and each piece sorts with `pieceDepthKey`. Lit-window pieces
  sort at key + 1, so people in front of a facade still cover its windows.
- Rooftop units / protesters on a roof use `roof.frontKey + n` (just in front of the whole
  building); roof highlights `frontKey + 1`, the rooftop placement ghost `frontKey + 2`.
- Ground UI (tile highlights, range ring) lives in `marks` under every standing thing — buildings in
  front hide it. Upright UI (waypoint flag, placement ghost) sorts in `entities`.
- Occlusion (`view/occlusion.ts`): per tile 0 visible / 1 feet hidden / 2 fully hidden (feet,
  head and shoulders covered). Silhouettes are drawn only for level 2 — a flat silhouette over a
  partly visible sprite would hide its art. The placement ghost x-rays (moves to `overlays`,
  alpha 0.5) at level ≥ 1.
- Off-screen static buckets (16×16-tile chunks) are detached from their containers so the
  per-frame entity sort stays small.

## 4. Look & feel rules

- **Grade** (`view/daylight.ts`): multiply tint from the time of day (0.1 day, .4 golden, .55
  dusk, .7 night, .95 dawn), quantised so static sprites re-tint rarely. People/vehicles get the
  grade mixed 30 % toward white (they read at night); **tear gas** 55 % toward white (stays
  gas-green); lit windows, lamps and fire are untinted.
- **Additive lights** (`lights`): never stack. `FxSystem.spawn` drops a light FX if one of the same
  clip is alive within ~0.4 × its width; fire-area glows merge within 40×22 px (≤ 16 per frame)
  at alpha 0.03 + 0.24 × darkness; molotov/car-fire flickers 0.3, blasts 0.35–0.4 for ≤ 0.25 s.
  (Additive orange over the purple night grade turns pink → white when stacked; that was the
  "pink blob" bug.)
- **Silhouettes** (`view/silhouette.ts`): each frame is copied once into a 1024² silhouette
  atlas as white (1-px solid rim + ~22 % fill; cast shadows dropped) and tinted by the ghost layer
  (ally `blue2`, enemy `crim2`). Allies: people only (no vehicle boxes), ≤ 16 per frame.
  Enemies: only prophets and cultists, ≤ 8 per frame. Off on the `low` tier.
- **Hate fists** (`view/juice.ts`): pop (0.16 s rise) → fly 0.6 s (cubic in-out, small arc) to
  `hateTarget` → `hatePickupArrived {amount}`. Deaths near a fist that is still popping merge
  into it (one fist "+12"); at most 10 fly at once (overflow joins the youngest). Off-screen kills
  emit `hatePickupArrived` immediately.
- **Signs**: only ≈12 % of protesters (of types that have both looks) raise a sign/placard/flag
  (`SIGN_SHARE` in `protesterView.ts`) — dense crowds otherwise become a wall of rectangles.
- **Rooftop deploy** (sniper, brigade): every free rooftop gets a pulsing lime outline + checker on
  its standable roof surface (`roofHighlight`), the hovered roof turns hi-vis (or red if taken /
  not allowed) with the unit ghost standing on it. Pointing anywhere on a building's walls or roof
  picks it (`WorldView.roofAt`). Ground deploy keeps the tile diamonds around the cursor.
- Range ring only for attack range ≥ 1.5 tiles.
- Shake / hit-stop on big explosions and Capitol damage; `juice.reducedMotion` disables shake.

## 5. Controller API (for M9)

```ts
const game = window.__riot.game;            // GameController
game.bus.on('hatePickupArrived', ({ amount }) => bumpHateCounter(amount));
game.setHateTarget(x, y);                   // UI px of the HUD Hate counter (fists fly there)
game.hud();                                 // HudSnapshot: hate, legit, level, nextLevelAt, progress,
                                            // wave, phase, breather, crowd, pending, integrity,
                                            // capitolState, paused, speed, tod, hour, outcome
game.deployOptions();                       // [{unit, cost, hotkey, unlocked, affordable, level}]
game.beginDeploy('riot' | null);            // toggle deploy mode (same unit again = leave)
game.deployAt(i, j);                        // returns Unit | null (emits deployFailed)
game.tap(e) / game.hover(info) / game.tapTile(i, j)
game.select(id | null); game.commandTo(i, j); game.useAbility(id); game.useAllAbilities();
game.startWaves();                          // prep → waves; during a breather: next wave early
game.callNextWaveEarly();
game.setPaused(b); game.togglePause(); game.setSpeed(1|2|3); game.cycleSpeed(); game.cancel();
game.focusTile(i, j); game.keepPlacing = true;
game.onFrame = (dtMs) => …; game.onSimEvents = (events) => …;   // raw drained sim events
game.perf                                    // {sim, view, render, frames} accumulated ms
```

Touch deploy: first tap previews (ghost + highlights), a second tap on the same tile (or the same
building, for rooftop units) confirms. Rooftop units: `tap`/`hover` resolve the building under the
pointer; `tapTile(i, j)` in deploy mode deploys at exactly (i, j).

### Events on `game.bus`

All sim events (`docs/M6.md`: `spawned unitDeployed commanded died unitDied attacked fired
exploded areaCreated thrownOffRoof climbStart reachedRoof abilityReady abilityUsed flash
bretaSpawned levelUp waveStart waveEnd capitolDamaged capitolState hateGained hateSpent
legitGained defeat victory`) plus:

| Event                           | Payload                 | When                                                                                  |
| ------------------------------- | ----------------------- | ------------------------------------------------------------------------------------- |
| `hatePickupArrived`             | `{amount}`              | a Hate fist reached `hateTarget` (bump the counter now)                               |
| `deployModeChanged`             | `{unit \| null}`        | deploy mode entered / left                                                            |
| `deployFailed`                  | `{unit, reason, i, j}`  | rejected placement (`phase locked hate bounds notRoad occupied notRooftop roofTaken`) |
| `selectionChanged`              | `{unitId, unit}`        |                                                                                       |
| `pauseChanged` / `speedChanged` | `{paused}` / `{speed}`  |                                                                                       |
| `timeOfDay`                     | `{tod, hour, darkness}` | every ~1/100 day                                                                      |
| `gameOver`                      | `{victory, stats}`      | once, after the sim's victory/defeat                                                  |
| `ready`                         | `{city, bootMs}`        | first frame on screen                                                                 |
| `artComplete`                   | `{ms}`                  | all deferred art installed                                                            |

M9 notes: the HUD Hate counter should only count up on `hatePickupArrived` (the sim's `hate` is
already higher while fists fly). The debug HUD (`game/debugHud.ts`) and `game/input.ts` are
placeholders for M9's HUD and input module. `document.documentElement.dataset.ready = 'true'` is set
after all art (screenshot tools wait for it).

## 6. Art loading (`game/assets/`)

Art is generated in code; at boot it is painted in Web Workers (`worker.ts` → `runJob`), each job
packing its own atlas (`packSprites`) that the main thread installs (`installPacked`, buffer-backed
textures merged into the global `art`). Pool = `hardwareConcurrency` (2–6), longest job first,
inline fallback without workers. Production builds cache job results in IndexedDB keyed by the
hashed worker URL (`?nocache` bypasses).

| Stage                         | Jobs                                                                                                                                                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| critical (before first frame) | units · fx (FX, markers, cursors, props, decals) · capitol state 0 · landmarks · buildings ×3 · ground **around the camera start** (`terrain region:'near'` ×2) · 3 looks each of student/woke/mob |
| deferred 1                    | far ground (`region:'far'` ×4) · remaining looks · breta, violent, paparazzi, crazy, cultist, prophet                                                                                              |
| deferred 2                    | vehicles · uikit · capitol states 1–4                                                                                                                                                              |

That is the **lean** plan for normal play (the run opens in the prep phase at the camera start).
Debug jumps (`?t`, `?stress`, `?scene`, `?focus`, `?u/v`) use the full plan (all ground, 8
looks of every early type before the first frame). Views tolerate missing art: protesters borrow
the closest available look (and re-pick their own once it arrives — `ProtesterView.refreshLooks`), the Capitol shows the nearest built state, terrain chunks are added
as they arrive (`TerrainView.add`, back-to-front zIndex).

## 7. Debug params (`game/params.ts`)

`city seed mapSeed autoplay=1 t=SECONDS stress=N level hate wave tod=0..1 quality=low|mobile|desktop
zoom u v focus=crowd|climb|gas|units scene=showcase|climb|gas freeze debug hud=0 nocache mute demo=1`

`scene=gas` (M14): the grenade is thrown 1 s before the end of the `t` skip, on a crowd standing in the open — `?city=madrid&scene=gas&t=3.5&focus=gas&zoom=4&freeze`.

Good shots: `?city=london&autoplay=1&t=50&level=7&hate=1200&wave=14&focus=crowd&hud=0&tod=0.12&zoom=3`
(night: `tod=0.75`). Paris/Madrid crowds die fast against a rich bot: keep `hate` ≤ 1500.
`window.__riot = {stage, game, world, map, camera, input, loop, view, timings, overlay}`;
`view.timing` accumulates per-sub-view ms; `__riotAudio` is the M11 engine.

| Scene                                | view JS / frame         | Pixi render JS / frame | notes             |

| London battle, 780 alive / 667 drawn | 1.0 ms (protesters 0.5) | 2.5 ms                 | 1440×900          |
| Madrid `?stress=3000`, 1936 drawn    | 2.2 ms (protesters 1.9) | 3.7 ms                 | sim ≈ 2 ms / tick |

Boot, first visit (`?nocache`), time to first game frame:

| City   | before (full critical set) | now (lean plan) |
| ------ | -------------------------- | --------------- |
| Madrid | 2.6 s                      | 2.2 s           |
| London | 3.5 s                      | 2.4 s           |
| Paris  | —                          | 2.3 s           |

All art (deferred stages) ≈ 7.5 s; cached reload ≈ 0.6 s. The near-ground terrain jobs dominate
(each worker pays the ground-tile generation warm-up), then landmarks and buildings.

## 10. Known issues / next

- Unit hit-flash frames are full white silhouettes (M4a art, 1/12 s); the view flashes a unit at
  most every 1.2 s so units in melee do not strobe.
- Enemy silhouettes are deliberately sparse (prophets/cultists only); a "crowd behind this block"
  indicator could be an M9 HUD marker instead.
- Further boot wins: share ground-tile frames across terrain jobs, split landmarks near/far.
- Optional polish: chimney smoke, health bars, heli bank poses, fading buildings near the selection.
