# M5 — FX & UI kit ("The Ministry Dossier")

237 registered sprites (FX: `fx`, world markers + UI: `ui`, fonts: `font`, portraits: `portraits-ui`),
plus DOM-free generators for anything that needs dynamic content (text, panels at any size, cards,
meters, stamps, banners, newspapers). All palette-pure RIOT-64; no partial alpha anywhere (lights are
opaque and meant for **additive** blending). Tests: `tests/fx-registry.test.ts`,
`tests/uikit-text.test.ts`, `tests/uikit-registry.test.ts`.

Previews: `docs/progress/m5-hud.png` (HUD at 1440×900, UI scale 3 over the M1 scene),
`m5-fx.png` (FX at 4×), `m5-fonts.png` (3×), `m5-title.png` (logo + victory/defeat front pages, 2×).

Code: `src/art/fx/` (`registerFx`), `src/art/uikit/` (`registerUiKit`). Shared drawing kit:
`src/art/fx/draw.ts` (`paintLobes` puff painter, `paintFlames`, ellipses/rings, masks, `chamfer`).

**Anchor convention**: pixel the sprite is placed at. Ground FX → ground contact point; flashes →
the muzzle pixel; overlays (KO, sweat, anger) → top of the head; world rings → centre on the
entity's foot; tile highlights → `{16,0}` (tile top vertex, same as tiles); UI → top-left `{0,0}`
unless noted.

## 2. Bitmap fonts & text API (`src/art/uikit/text.ts`)

| Font | Cap height | Line height | Notes |
|---|---|---|---|
| `FONTS.small` | 7 (x-height 5, desc 2) | 11 | proportional, upper + lower case, tabular digits (5 px) |
| `FONTS.smallBold` | 7 | 11 | faux-bold of small (HUD numbers, labels, buttons) |
| `FONTS.mono` | 7 | 11 | typewriter: fixed 6-px cell (advisor text, dossiers) |
| `FONTS.large` | 12 (desc 3) | 18 | chunky display, 2-px stems, **upper-case only** (input is upper-cased) |

Charset (all): A–Z, 0–9, `! ? ¡ ¿ . , : ; - + = × ' " / ( ) % # & £ € * < >` (small also `_ · « » °`),
accented á é í ó ú à è ì ò ù â ê î ô û ä ë ï ö ü ã õ ñ ç ÿ and capitals (composed from base glyph +
accent mark; accents sit above the cap line, cedilla below the baseline). Unknown chars → `?`.
Per-glyph advance + kerning pairs (`T a`, `L T`, `A V`, …).

```ts
measureText(font, str, maxWidth?, tracking?) → { w, h, lines }   // h = cap top → last baseline
lineWidth(font, line, tracking?) / wrapText(font, str, maxWidth, tracking?)
drawText(buf, font, str, x, y, colour, opts?) → buf               // (x, y) = cap-line top-left
  opts: { outline?, outlineThin?, shadow?, shadowOffset?, ramp?: string[] (vertical bands),
          align?: 'left'|'center'|'right' (x = left / centre / right edge), maxWidth?, lineGap?,
          tracking? (default 1 with a thick outline so letters never fuse) }
textSprite(font, str, colour, opts?) → PixelBuffer                // tightly trimmed
// Pixi (browser): src/art/uikit/pixi.ts
bufferTexture(buf) → Texture ; textTexture('small' | 'smallBold' | 'mono' | 'large', str, colour, opts)
```
Titles look best as `large` + `{ outline: 'ink', shadow: 'rust0', ramp: ['white','stone5','stone4'] }`.
Bigger display sizes: `textMask(font, str, scale)` (integer ×N, used by the logo/newspapers) or
`scaleBuffer(buf, n)`. Specimens: `ui.font.small|smallbold|mono|large.specimen` (group `font`).

## 3. Panels — 9-slice (`src/art/uikit/panels.ts`)

Preferred: `panel(kind, w, h)` draws pixel-exact at any size (patterns stay crisp).
For Pixi `NineSliceSprite`, use the registered source `ui.panel.<kind>` with `NINE_SLICE[kind]`
(insets = also the safe content padding):

| kind | source | left | top | right | bottom | use |
|---|---|---|---|---|---|---|

| `paper` | 24×20 | 10 | 4 | 4 | 5 | typewritten sheet with red margin |
| `brass` | 24×24 | 6 | 6 | 6 | 7 | plaques, portrait frames, name tags |
| `leather` | 32×32 | 7 | 7 | 7 | 8 | HUD bars (stitched; use `panel()` — stitching should not stretch) |
| `tooltip` | 16×16 | 4 | 6 | 4 | 5 | index card tooltip |
| `bubble` | 24×20 | 6 | 5 | 6 | 7 | advisor speech bubble (+ `ui.panel.bubble.tail.left` anchor 7,4 / `.tail.down` 3,0) |

| `recess` | 12×12 | 2 | 3 | 2 | 2 | dark inset (portrait / map wells) |

## Requests / notes for integrators

- Lights are opaque palette colours: put them on a light layer with additive blending.
- Gas/smoke/fire are fully opaque cartoon clusters (no translucency) — they read on every ground.
- Shared-change requests: none required. Nice-to-have: let `tools/export-sprites.mjs` take a
  module path (so milestones can export their own registries while other modules are mid-edit).
