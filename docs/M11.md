# M11 — Procedural audio

Everything is synthesised with WebAudio at runtime. There are no audio files and no dependencies.
The module lives in `src/audio/`. It imports nothing from `game/`, `view/` or `ui/`, only
types from `sim/`, `data/` and `maps/`, plus `core/iso` and `core/rng`.

## API

```ts
import { createAudio, busSource } from './audio';

const audio = createAudio();          // cheap: no AudioContext until unlock
audio.autoUnlock();                   // window gesture listeners: unlock + re-resume (iOS)
// or call audio.unlock() inside your first pointer/key handler

audio.setCity('madrid');              // or null → "Ministry" flavour
audio.setMusicState({ phase: 'prep', level: 0, crowd: 0, night: false });   // partial updates OK
audio.play('click');                  // UI (non-positional)
audio.play('pistol', { x, y, volume, pitch, delay });   // x/y = WORLD pixels
audio.loop('veh:12', 'heliLoop', { x, y, volume, rate, ttl });  // keep-alive: refresh every frame
audio.stopLoop('veh:12');
audio.setCrowd({ size, anger?, near? });
audio.setListener(camera.center, camera.zoom, canvas.width);    // zoom & width in device px
audio.setVolume('music', 0.5);        // 'master' | 'music' | 'sfx' | 'ui' | 'ambience' (0…1, persisted)
audio.mute();                         // toggle (or mute(true/false)); persisted; suspends the context
audio.getSettings(); audio.stats(); audio.dispose();
```

`MusicState.phase`: `'menu' | 'prep' | 'wave' | 'breather' | 'victory' | 'defeat'`.

## Wiring it in (M8 / M9)

**M8 (world view)**, once at boot and every frame:

```ts
const audio = createAudio();
audio.autoUnlock();
// Option A (simplest): you already drain world.events once per frame:
const batch = world.events.drain();
view.handle(batch);
audio.handleSimEvents(batch);
// Option B: you dispatch to an EventBus<SimEventMap> → audio.bindSimEvents(busSource(bus), opts)

audio.bindSimEvents(null, {               // null source = fed through handleSimEvents
  capitol: capitolWorldPos,               // world px (Capitol damage sounds)
  unitType: (id) => world.units.get(id)?.type,    // optional fallback
  units: () => world.units.active,        // vehicles get engine/rotor loops that follow them
  crowd: () => world.crowd.count,         // crowd bed size (any "alive protesters" number)
});
// per frame (after the camera moves):
audio.setListener({ x: camera.x, y: camera.y }, camera.zoom, canvas.width);
```

- `units` is polled about 10 times a second. Items need `{ id, type, x, y, moving? }` in **tile**
  coordinates (the sim's `Unit` objects fit). Humvees, tanks and helis get `humveeLoop`, `tankLoop`
  and `heliLoop`, with Doppler pitch from their motion, louder and faster while `moving`.
- Crowd anger is derived from recent combat activity. Pass `setCrowd({ anger })` to override it,
  and `near` (0…1, the share of the crowd near the camera) for a louder, brighter bed when zoomed
  into the fight.
- Night: `audio.setMusicState({ night: true })` switches the march to its minor, ticking variant.

**M9 (UI and screens)**:

```ts
audio.setMusicState({ phase: 'menu' });                    // title / city select (hold music, phone EQ)
audio.setCity(city); audio.setMusicState({ phase: 'prep', level: 0, crowd: 0 });
// director phase → music (call on change, and every ~1 s for level/crowd):
audio.setMusicState({ phase: inWave ? 'wave' : 'breather', level: world.level, crowd: world.crowd.count });
// end screens (the sim's victory/defeat events already play the stinger):
audio.setMusicState({ phase: 'victory' }) / ({ phase: 'defeat' });
// UI sounds:
button hover → 'hover', click → 'click', invalid placement → 'error',
unlock card / newspaper → 'stamp', advisor typewriter → 'typeTick' per character (+ 'typeBell' at the end).
// settings panel → setVolume / mute / getSettings
```

Do **not** play `deploy`, `levelUp`, `waveAlarm`, `legitStamp`, `hateChing`, `abilityReady` or the
victory/defeat stingers from the UI. The sim events already trigger them.

## Sim event → sound mapping (`SIM_EVENT_AUDIO`)

Positions are converted from tile to world coordinates. "UI" means non-positional on the ui bus.

| Event | Sound |
|---|---|
| `spawned` | `doorOpen` at the door (quiet, heavily rate-limited) |
| `unitDeployed` | `deploy` (UI) + per unit: riot `shieldThud`, blockade `blockadeSlam`, mounted `horseWhinny`, humvee `humveeRev`, tank `tankTracks`, heli `heliPass`, gas `canisterPop`, others `bolt` (rack). Also records unit id → type |
| `commanded` | mounted `hooves`, humvee `humveeRev`, tank `tankTracks`, heli `heliPass`, else `click` |
| `died` | `bodyFall`; KO (non-lethal): 35% `koBoing`, 20% `dizzy`; crush → `crunch`; Breta → `koBoing` + `paparazzi` + `crowdBoo` |
| `unitDied` | blockade `metalWreck`; humvee/tank `explosionBig` + `metalWreck`; mounted `horseWhinny`; others `bodyFall` (skipped if thrown off) + police `whistle` |
| `attacked` | unit melee: `baton` (mounted: `bat`); protester melee on riot `shieldThud`, on blockade/humvee/tank `metalHit`, else `punch`; protester bullets `bulletHit` (vehicles: `ricochet`); on Capitol `capitolHit`; crush `crunch`; explosion/gas/fire ignored (covered by other events) |
| `fired` | rubber `rubberPop` + delayed `rubberHit` at the impact; pistol `pistol`; rifle `rifle` (bursts come as separate events); mg → keep-alive `mgLoop` per shooter; doorGun → `doorGunLoop`; sniper `sniper`; cannon `tankCannon`; bazooka `bazooka`; molotov `molotovThrow`; gasGrenade `canisterPop`; gasCone `gasSpray` (one per second while spraying); baton/bat/none ignored |
| `exploded` | shell `explosionBig`, bazooka `explosionMedium`, molotov `glassSmash` + `fireWhoosh`, gas grenade small `metalHit`, prophet `prophetBoom` |
| `areaCreated` | gas → `gasLoop`, fire → `fireLoop` at the area for its `ttl` |
| `thrownOffRoof` | `fallWhistle` at the roof, `bodyFall` at the landing 0.75 s later, a small `crowdRoar` |
| `abilityReady` | `abilityReady` chime (UI) |
| `flash` | `shutter` + `flashWhine` |
| `bretaSpawned` | `paparazzi` + `crowdRoar` |
| `levelUp` | `levelUp` fanfare (ducks music) |
| `waveStart` | `waveAlarm` klaxon + distant two-tone `siren` |
| `waveEnd` | police `whistle` |
| `capitolDamaged` | `capitolHit` at the Capitol |
| `capitolState` | `glassBreak` + `alarmBell` + `crowdRoar` |
| `hateGained` | `hateChing` (quiet for protester kills, louder for big payouts); call-early adds `stamp` |
| `legitGained` | `legitStamp` (ka-chunk + approval bell) |
| `victory` / `defeat` | `victoryStinger` / `defeatStinger` (duck music) |
| `climbStart`, `reachedRoof`, `abilityUsed`, `hateSpent` | **ignored** (too frequent, or another event carries the sound) |

## Engine design

- **Graph**: voices → bus (`sfx` / `ui` / `ambience`) → volume → duck → master → glue compressor
  (−16 dB, 4:1) → limiter (−3 dB, 20:1, 1 ms) → ×0.9 → out. Music → EQ (the "phone" band-pass on the
  menu) → music bus. The sfx and music buses send to a cheap "room" made of two damped feedback
  delays. Explosions duck the ambience (crowd) bus by 4–6 dB. The level-up fanfare and stingers
  duck the music by 9–12 dB.
- **Baking**: frequent sounds are rendered once per variant (2–3 random seeds) into trimmed
  AudioBuffers with OfflineAudioContext. This happens right after unlock (loops, crowd grains,
  22 common SFX) or on first use, when the sound plays live once. After that a hit costs one
  buffer source plus gain, pan and optional low-pass. Rare or musical sounds (stingers,
  fanfare, siren, chants) stay live. If OfflineAudioContext is missing, everything plays live
  and loops are skipped.
- **Rate limiting** (`limiter.ts`), per frame (one microtask flush):
  1. Identical sounds in the same frame, pan sector and 50 ms delay bucket merge into one
     trigger. Gain is the loudest request × (1 + 0.3·log2 n), capped at ×2. At n ≥ 3 (and n ≥ 10)
     extra baked variants are layered with 10–60 ms offsets for a denser hit.
  2. A per-sound `minInterval` carries groups over to merge into a later trigger. They are
     dropped after 0.25 s.
  3. A per-sound voice cap steals the oldest voice.
  4. Global caps: at most 12 new voices per flush, a token bucket of 50 new voices/s (UI
     exempt), and 40 live voices. A newcomer may steal the weakest voice of lower priority.
     The priority order is UI > explosions > cannon/sniper > guns > hits > bodies > doors.
  5. Positional requests below gain 0.03 are culled before any work.
- **Spatial** (`spatial.ts`): normalised distance d = |Δ| / (half the visible world width), with
  vertical distance weighted ×1.6. Gain is 1 inside 0.75 of the half-width, then
  `(1 + 2.2(d − 0.75))^−1.6`, about 0.5 at the screen edge. Off-screen sounds also get a
  low-pass (`18 kHz / (1 + 5(d − 1))`). Pan is up to ±0.75. A zoom factor
  `(704 / visibleWorldW)^0.3`, clamped to 0.7…1.25, makes zoomed-in views louder.
- **Loops** are keep-alive emitters (`loop(key, id, opts)`). They expire after `ttl` without a
  refresh, fading in and out per loop type. Per loop type only the N loudest play: MG 3, door
  gun 2, fire 4, gas 3, heli 2, humvee 3, tank 3. Others stay virtual until they become loud
  enough. Loop buffers come from a render of length + crossfade with an equal-power seam
  (periodic parts use integer cycles per loop).
- **Lifecycle**: `unlock()` must run in a gesture. It creates the context synchronously, plays
  a silent buffer (iOS) and calls `resume()`. `autoUnlock` keeps cheap listeners so iOS
  "interrupted" contexts resume on the next tap. A hidden tab suspends the context, and mute
  suspends it too (zero audio CPU). `quality: 'low'` → 24 voices, 30 new voices/s, at most 2
  bake variants, music capped at layer 3.

## Music

| Phase | Theme | Notes |
|---|---|---|
| `menu` | Ministry hold music | F-major elevator waltz (3/4, 92–96 bpm): vibes and FM e-piano, through a 320–3400 Hz "telephone" EQ. |
| `prep` | Hold music, city flavour | **Madrid**: guitar waltz over an Andalusian cadence with castanets. **London**: slow brass-band chorale. **Paris**: accordion musette waltz (A minor ↔ E7). |
| `wave` | March, escalating | Ministry: B♭ 2/4 street march. **Madrid**: pasodoble with a minor Andalusian A section, a major trio, trumpet and castanets. **London**: broad 4/4 "Pomp"-style brass band in F. **Paris**: accordion polka-march. |
| `breather` | March "parade rest" vamp | Tuba, pahs and light snare, no melody. |
| `victory` | Fanfare that never resolves | A V7 resolves to a bare open fifth that sags a semitone flat: triumphant but hollow. Plays once. |
| `defeat` | D-minor dirge | Ends with the sad trombone ("wah wah wah waaah", with vibrato). Plays once. |

**Escalation**: `intensity = 0.1 + 0.055·level + 0.3·log10(1 + crowd) / 3.5` sets
`layer = 1 + ⌊4·intensity⌋`. Tempo rises across the style's range: Ministry 108→136, Madrid
112→132, London 96→120, Paris 116→140.

| Layer | Adds |
|---|---|
| L1 | Melody, tuba oom-pah, kick, light snare |
| L2 | Full snare cadence, horn pahs, rolls into section ends, castanets |
| L3 | Harmony line a third below, glockenspiel doubling, phrase crashes |
| L4 | Chiptune octave lead, a crash every bar, 32nd rolls and pickups |

**Night** (march only) switches to the parallel minor chord-scales, replaces the kick with
timpani, adds hi-hat ticking, drops the glock and runs about 6% slower.

**Composition**: each style has 8-bar chord progressions per section and a form (AABA etc.).
`composeSection` builds a seeded melody. Bars 1–2 set a rhythm motif that bars 5–6 repeat. The
melody arches up and then back down, with a half cadence in bar 4 and the tonic at the end.
Strong beats snap to chord tones, moving in the direction of motion and avoiding repeated
notes. Each chord carries its own chord-scale, so borrowed chords (E major in A minor, the
pasodoble trio) colour the melody correctly. The seed is fixed per engine (default 1), so each
city keeps a recognisable tune across runs.

**Transitions** happen on bar boundaries only. A new theme starts at bar 0. Going from hold to
march inserts a one-bar snare-roll and tuba walk-up pickup. Layer and night changes apply on
the next bar, and tempo changes on section starts.

## Crowd bed

- **Roar**: looping pink noise through three vowel formant band-passes. The vowel drifts every
  0.6–1.5 s. A brown-noise rumble is added for big crowds.
- **Level**: `log10(1 + size) / 3.48` (3000 → 1).
- **Anger** makes the bed brighter (formants ×1.18, low-pass up to about 3.3 kHz), louder, and
  shifts the grain mix toward hey/boo/whistles.
- **Grains**: baked glottal-saw syllables ("hey", "ho", "boo", "woo", "yeah", murmurs),
  whistles and crowd claps. The rate is `min(10, 0.6 + size/60) · (0.5 + anger)` per second,
  with random pans.
- **Chants**: with at least 25 protesters, every 10–30 s: "clap · clap · clap-clap-clap" ×3 +
  "HEY!", or "HO-HO! HEY-HEY!" ×3, or a boo swell when furious. Chants lock to the music's beat
  grid when music is playing. The layer count grows with crowd size.

## Measured (headless Chromium, `node src/audio/dev/check.mjs`)

- Every SFX is non-silent. Peaks at bus input are 0.03 (hover) … 0.88 (prophet boom). Loop seams
  are ≤ 0.013.
- The **stress** mix (200 hits/s at random positions, pistols 10/s, rifles 15/s, 2 explosions/s, a
  tank cannon, 3 MG loops, fire and heli loops, crowd 3000 angry, march L4) peaks at −2.2 dBFS
  with an RMS of −12.8 dBFS and **0 clipped samples**. 1321 requests became 305 voices.
  Offline render load is 0.14× real time on this box.
- **Real-time** run of the same stress test on the dev page: max −2.3 dBFS, 0 clipped samples.
- **Music**: −21 to −30 dBFS RMS, render load 0.02–0.15× real time.
- **Crowd bed alone**: −33 dBFS RMS at 60 people, −26 at 600, −23 at 3000 angry. SFX sit about
  8–10 dB above the music and crowd.

## Dev page and checks

  positions), toggle loops (with an x slider or an orbit for Doppler), music phase, city, level,
  crowd, night and anger, forced chants, volume sliders and mute, a stress button with a
  post-limiter peak meter and clip counter, live engine stats, and an offline render report.

  Vite dev server and Playwright Chromium. It runs a real-time smoke test, renders every SFX,
  loop and crowd grain offline (peak/RMS/seam), music for every phase and city, the crowd bed
  alone, and the stress mix. It exits 1 on silence, a hot sound or clipping.
- Tests (`npx vitest run tests/audio-`):
  - `audio-sim-mapping`: every event handled or ignored, valid ids, weapon, unit and KO
    mapping, tile→world, loops, `busSource`.
  - `audio-limiter`: aggregation, density boost, min-interval carry and staleness, voice caps
    and stealing, per-flush priority, token bucket.
  - `audio-music`: determinism, valid bars for every style/section/layer/night, chord-scale
    membership, cadences, escalation, vamp, city instruments, pickup.
  - `audio-settings`: persistence round trip, corrupt or throwing storage, sanitising, the
    engine persisting volume and mute without an AudioContext, spatial maths, loop crossfade,
    crowd scaling.

## Known gaps / ideas

- Nobody has listened to it yet. Levels and timbres were tuned by reasoning and by offline
  peak/RMS measurement. A listening pass should adjust `gain` in `sfx/catalog.ts` and the
  instrument levels in `music/instruments.ts`.
- The crowd bed is non-positional (pan is centred). It uses `near` for proximity but does not
  pan toward where the crowd is.
- Vehicle engines need the `units` provider (or manual `loop()` calls). Events alone only give
  start and command sounds.
- Baked buffers are mono at the context rate. Worst case is about 15 MB if every sound gets
  used; `quality: 'low'` limits variants.
- Chants use the music's beat only while music plays, otherwise 120 bpm.
- No reverb per city, no weather or ambient city loops (traffic, birds), no "Breta speech".
