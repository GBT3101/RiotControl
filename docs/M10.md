# M10 — Tutorial, hints & writing

The Minister of the Interior gets his voice: a first-run briefing, rate-limited contextual
hints, and all the satirical copy in one place. Code: `src/ui/tutorial/`, `src/ui/hints/`,
`src/ui/text/`. Screens: `docs/progress/m10-*.png`.

## 1. Tutorial (first-run briefing)

**When**: the first run in each city (`settings.tutorialDone[city]`), or the next run after
Settings → TUTORIAL REPLAY (`settings.replayTutorial`; it also forgets the seen hints).
Never in the title-screen attract game or in debug-jump runs (`autoplay`, `t`, `level`,
`wave`, `scene`, `stress`, `moment`, `freeze`, `hud=0`). `?tutorial=0` disables it,
`?tutorial=1` forces it (with any other params), `?tstep=N` starts at step N (screenshots).
Finishing **or** skipping sets `tutorialDone[city]` and clears the replay flag.

**Never blocks**: the game keeps running (no pause, no slow-mo — every action step is done in
the untimed prep phase, the later ones are read-only lines during waves). The overlay is not
interactive; only the **SKIP BRIEFING** stamp button (above the Minister) is. Steps advance
on the player's actual actions; a step whose action already happened is skipped.

| #   | Step      | Pointer (pulsing hi-vis brackets + bobbing arrow, light dim)                    | Shows when                      | Advances on                                                    |
| --- | --------- | ------------------------------------------------------------------------------- | ------------------------------- | -------------------------------------------------------------- |
| 0   | `welcome` | —                                                                               | run start                       | lines read                                                     |
| 1   | `pan`     | white-gloved hand sliding over a ⟷ (drag / wheel; pinch)                        | —                               | camera moved > 40 px or zoom changed; else 14 s                |
| 2   | `deploy`  | Riot Control card **+** a Capitol-steps tile (camera eases there if off-screen) | —                               | `unitDeployed`                                                 |

The opening follows the M12 playtests: Riot Control on the Capitol steps first, then a line on
the busiest approach, snipers on roofs next to riot cops.

**Code**

- `tutorial/machine.ts` — pure step machine (`TUTORIAL_STEPS`, `TutorialMachine`: `fact()`,
  `linesFinished()`, `update(dt, calm)`, `skip()`; hooks `show / leave / finish`).
- `tutorial/geometry.ts` — pure: `tutorialParam`, `shouldRunTutorial`, `completeTutorial`,
  `dimRects` (screen minus highlight holes), `placeAdvisor` (keeps the Minister off the
  highlighted rects and arrows: default spot → just above the zones → under the top bar →
  least overlap on cramped phones).
- `tutorial/tutorial.ts` — Pixi runtime (`ui.tutorial`): listens to `game.bus`, resolves the
  targets each frame (`ui.hud.deploy.cardRect`, `ui.hud.wave.rect`, new `top.hateRect /
legitRect / integRect`, world tile → UI px via the camera), draws the pointers and the dim
  (a `Graphics` of `ink` rects at 32 % alpha), positions SKIP BRIEFING, picks the suggested
  tile (`suggestTile`: visible deployable Capitol step, else nearest the chokepoint closest to
  the Capitol; `game.view.occlusionAt` = 0 so it is never behind a building).
- `tutorial/art.ts` — hand-authored grids: arrow down/up (13×12), frame corner (8×8 ×4),
  glove hand (13×15), drag arrow (15×7). RIOT-64, lit from the upper-left, ink outlines.

## 2. Contextual hints

`hints/scheduler.ts` (pure): offers → **one hint per 20 s** at most, highest priority first
(older first on ties), offers older than their `ttl` are dropped, duplicates ignored,
`once: 'profile' | 'run' | 'never'`. Game time only (no ticking while paused / in a menu).
Profile-once hints persist in localStorage `riot.hints.v1` (`{seen: string[]}`).
Advisor hints wait while the tutorial runs, a level-up dossier / wave banner is on screen, or
the Minister is talking. Toast hints use the M9 alert stack (navy band, figure icon).

(ignores rate limit and seen state), e.g. `?hint=gasCharged`, `?hint=capitol3`,

`src/ui/strings.ts` re-exports everything (M9 imports keep working); `src/game/tips.ts`
re-exports `TIPS` for the loading screen. Wired: deploy-card tooltips and unlock dossiers
(units), NEW THREAT alerts (codex), Capitol alerts (per state), Breta / Prophets alerts, deploy
toasts, wave banner sub-line, end screen deck + closing line (seeded per run), loading tips,
breather memos.

**Tone rules** (PLAN §1.10): both sides are the joke — deadpan cynical bureaucracy vs
earnest-absurd protesters; no slurs, no real politicians, no real religions or ethnicities
(the cult is the fictional Order of the Final Hour; Breta is a gentle parody).

### Adding strings

1. Put the copy in the matching `src/ui/text/*.ts` module (new area → new module, export it
   from `text/index.ts`). Never inline player-facing text in widgets.
2. Use only glyphs the bitmap fonts have (Latin-1 letters incl. á é í ó ú ñ ç à è ê ô ü,
   `¡ ¿ £ € « » ° · × * _ < > # & %` …) — **no** `…` `—` `✔` or curly quotes: write `...`, `-`, `"`.
3. Respect the slot: advisor lines ≤ 86 chars (≤ 3 lines in the desktop bubble, ≤ 5 on a
   portrait phone), alert lines ≤ 64, tips ≤ 120 (≤ 3 lines), decks ≤ 96 (2 lines), closers
   ≤ 42 with a ". " split into ≤ 34-char halves, dossier notes ≤ 19 chars per line.
4. `npx vitest run tests/ui-tutorial-text` enforces all of the above (non-empty, glyphs,
   lengths, wrapped line counts).

- `tools/smoke.mjs`: main flow uses `?tutorial=0`; new block: the briefing shows on a fresh

## 6. Notes / known issues

- Partial-alpha _sprites_ stretched from a tiny canvas texture did not render in this Pixi
  setup while they were re-laid out every frame; the dim is a `Graphics` (rects re-built only
  when they change). Worth a look in M13.
- The Minister's default spot overlaps the LET THEM COME button in prep (M9 layout); during
  the briefing the advisor moves out of the way of whatever is highlighted.
- Each advisor line slides in from the left (M9 behaviour), including consecutive lines.
