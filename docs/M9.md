# M9 — UI/UX & screens

The whole UI is drawn with Pixi from the M5 kit (`src/art/uikit`) and the worker-built atlas,
at an integer UI scale, in the same frame as the world. Code: `src/ui/`. Screens:
`docs/progress/m9-*.png`.

## 1. Screen flow

```
index.html ─┬─ ?city=… / ?skipTitle=1 ─────────────────────────────► run (HUD)
            └─ (no city) loading → TITLE ──PLAY──► CITY SELECT ──DEPLOY──► (loading if needed) → run
                 ▲  living city backdrop          (same backdrop, dimmed)          │
                 │  SETTINGS · CREDITS                                              ▼
                 └───────────────── TITLE ◄── QUIT ── PAUSE (Esc / ⏸) ⇄ SETTINGS
                                         ◄── END: newspaper → ledger → "But at what cost?"
                                               PLAY AGAIN · OTHER CITY (→ select) · TITLE
```

- **Title**: an _attract-mode_ game runs underneath (`createGame(..., { attract: true })`: a bot
  plays wave 3 / level 4, no SFX, menu music); the camera drifts toward the densest crowd,
  offset so it sits beside the menu. Logo glint every 3 s, PLAY / SETTINGS / CREDITS, parody
  disclaimer. Phone landscape: logo left, menu right. Enter = PLAY.
- **City select**: three dossier postcards. The photo is the real Capitol art: the loaded city
  is reassembled from its depth pieces in the atlas (`assemblePieces`), the other two are painted
  by a throwaway worker pool (`capitolPictures`, nothing goes to the GPU), cropped to the densest
  window (`postcardCrop`). Best result from localStorage, or a CLASSIFIED stamp. Portrait: cards
  stack horizontally-laid-out. Keys 1/2/3 pick, Esc back.
- **Art reuse**: `ArtStore` (game/boot.ts) keeps city-independent atlases (units, FX, vehicles,
  UI kit) for the page's lifetime and one `ArtSession` per city. Same city again (restart, play
  the title backdrop city) = instant, no loading. Another city disposes the previous city's
  atlas pages (`ArtSession.dispose`) and shows the loading screen.
- **End**: `gameOver` → records saved → 1.7 s later the `EndScreen` (see §4).

## 2. Architecture (`src/ui/`)

| File                                        | What                                                                                                                    |
| ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `app.ts`                                    | `UiApp`: stage, UI layers, input router, art store, running game, screen stack, flow, debug moments, `window.__riot.ui` |
| `layout.ts`                                 | Pure responsive layout (`computeHudLayout`), scroll helpers, safe-area insets → UI px                                   |
| `model.ts`                                  | Pure HUD logic: `cardState`, `HateCounter`, `levelProgress`, `waveStatus`, `callEarlyBonus`                             |
| `settings.ts` / `records.ts` / `storage.ts` | localStorage (`riot.settings.v1`, `riot.records.v1`), all try/catch                                                     |
| `strings.ts`                                | UI copy (unit roles/quips/dossier notes, threat lines, city taglines, credits) — M10 moves it to `src/data/strings/`    |
| `art.ts`                                    | Atlas read-back (unit portraits, protester figures), compact deploy card (30×38), helpers                               |
| `core/`                                     | `node.ts` (interactive nodes + hit test), `input.ts` (router), `button.ts`, `label.ts`, `tex.ts`, `anim.ts`             |
| `hud/`                                      | `hud.ts` + `topBar`, `deployBar`, `waveButton`, `minimap`, `infoPanel`, `placement`                                     |
| `widgets/`                                  | `advisor.ts`, `moments.ts` (level-up dossier, wave banner, alerts, info toasts), `tooltip.ts`                           |
| `screens/`                                  | `title`, `citySelect`, `pause`, `settings`, `credits`, `end`, `common` (dossier folder, headings, dither)               |

**Layers** (stage children, bottom → top): game world · `hudLayer` (HUD, moments, advisor) ·
game screen-FX (Hate fists fly _over_ the HUD into the counter, level-up confetti) · `topLayer`
(screens, tooltip). `UiApp.restack()` keeps this order whenever a game is (re)created. Both UI
layers are scaled by the UI scale; everything inside is in UI px.

**Input**: `core/input.ts` listens in the _capture_ phase on the game host element, so it sees
every pointer event before the canvas (camera controller). A press that starts on a UI node is
stopped there and routed (tap, long-press, hover, drag-scroll, wheel); presses that start on the
world pass through, even if they later move over the HUD. Any object becomes interactive with
`makeInteractive(container, { tap, hover, longPress, drag, wheel, hit, blockOnly })`. Mouse
hover over the UI clears the world hover ghost. Modal screens put a full-screen `blockOnly`
backdrop under their panel.

**Frames**: the game loop calls `controller.onPreRender` (new hook) → `UiApp.frame(dt)` right
before `app.render()`; without a game the app runs its own RAF. UI animations use real time (dt
capped at 0.25 s, so slow headless renders still progress).

**Controller additions** (API stable, documented in game/controller.ts): `onPreRender`,
`attract`, `destroyed`, `destroy()` now removes the world view (`WorldView.destroy`), `preview`
(touch preview tile) + `confirmPreview()`, `HOTKEYS.heli = '-'`.

**UI scale** (`render/zoom.ts uiScale`, changed in M9): the largest integer device-px scale that
keeps ≥ ~300 UI px on the short side, never below 2 CSS px per UI px (1.5 on phone-sized
screens): 1440×900 → 480×300 UI px, 1920×1080 → 640×360, 768×1024 → 384×512, 844×390@3 →
506×234, 390×844@3 → 234×506.

## 3. HUD

- **Top bar** (leather): Hate (counts up only on `hatePickupArrived`; `setHateTarget` points at
  it every layout; spending is immediate; catches up if a fist is lost), Legitimacy seal + bar
  (progress from this level's threshold to the next; tooltip with numbers and the next unit),
  Capitol integrity (cracks; shakes on damage-state change, flashes on hits; tap = look at the
  Capitol), wave / `PREP` / `NEXT 12s`, crowd (alive + queued), ⏸ (quick-pause resume / pause
  menu), speed 1×/2×/3×, mute, settings. Two rows when narrower than 440 UI px; `lg` buttons
  on touch. Numbers compact (`12.3k`) in two-row mode.
- **Deploy bar**: all 11 units in order. Kit cards (38×50, hotkey tab) on large screens, compact
  cards on phones. States derive from `deployOptions()` + `deployUnit` (`cardState`). Locked /
  unaffordable taps shake the card, play `error` and toast why. Hover (desktop) / long-press
  (touch) / right-click → index-card tooltip (name, hotkey, role, cost, Legit on death, quip).
  Scrolls horizontally (drag with inertia, wheel) when it doesn't fit — the portrait bottom sheet.
- **Wave button**: LET THEM COME (bobbing big red button) in prep; CALL EARLY +N (bonus =
  `floor(breather × callEarlyFactor)`) with a countdown during breathers; hidden during waves.
- **Minimap**: true 2:1 iso projection in the brass bezel (`minimapTiles` / `minimapBase`
  pure); overlay at ~6 Hz: crowd heat (per-tile `hash.cellCount`), unit blips (selected one
  blinks), camera rectangle. Tap/drag moves the camera. Phones: toggle button (Tab on desktop);
  hidden by default in portrait.
- **Unit panel** (paper sheet, bottom-left): portrait, name, HP bar (squads: men left;
  helicopter: INVULNERABLE), role, kills (counted from `died.by`), blinking "TAP A ROAD TO MOVE"
  for commandables, gas charge ring + pulsing THROW GAS. Charged gas shooters also get a
  bouncing grenade cue over their heads in the world (tap = throw).
- **Placement**: hint strip while deploying (desktop: Shift keeps placing · Esc cancels; touch:
  ✖ next to it). Touch: first tap previews (controller), then ✔/✖ appear next to the ghost.
  `deployFailed` → reason toast (`failText`) + `error`.
- **Quick pause** (Space): a PAUSED stamp; tap it or Space to resume.

## 4. Moments, advisor, end screens

- Level-up: ribbon "NEW TOOL OF ORDER APPROVED" bounces in, the unlock dossier (FILE nn tab,
  deploy card, typed notes, footnote, paper clip) slides under it, APPROVED and LEVEL n stamps
  slam down (`stamp` sfx). 6.5 s, tap to dismiss; queued; the game keeps running. New protester
  types → "NEW THREAT: …" alert with the protester's figure; Prophets also get a hazard alert.
- Alerts stack top-left and slide in: threat, Breta sighted (tap → camera), Capitol damage state
  (tap → camera), Prophets. Wave start → hazard-tape WAVE n INCOMING banner slides across.
- **End screen**: newspaper `frontPage` spins in; its picture box gets a live photo — the world
  rendered at 1× around the Capitol into a RenderTexture, extracted and reprinted as a
  palette-pure dithered newsprint halftone (`newsprintPhoto`); APPROVED / DENIED stamp lands.
  Then the ledger dossier (protesters fallen by type with mini heads, officers lost by type with
  mini portraits, Breta, Hate earned/spent, peak crowd, waves, time, Capitol damage, NEW RECORD
  stamp) types its rows in; then the closing line types out slowly in ×2 typewriter letters:
  **"You kept order. But at what cost?"** (defeat: "You lost order. It cost exactly the same.");
  then PLAY AGAIN · OTHER CITY · TITLE. Taps / Enter / Space fast-forward. Wide screens show
  paper and ledger side by side; phones use 3 (landscape) or 1 (portrait, drag-scroll) columns.

### Advisor API (for M10)

```ts
const ui = window.__riot.ui; // UiApp
await ui.advisor.say('Press LET THEM COME.', 'idle', { sticky: true }); // resolves on dismiss
ui.advisor.say('Every fallen officer makes us MORE legitimate.', 'smug'); // queued, auto-dismiss
ui.advisor.clear();
ui.advisor.speaking;
// moods: 'idle' | 'smug' | 'sweat' | 'panic'; opts: { sticky, hold, cps, speaker }
```

Minister portrait box + name plate + speech bubble; typewriter at 38 cps with `typeTick` every
2nd character and `typeBell` at the end; lip-flap mouths from the characters; tap completes the
text, next tap dismisses. It sits bottom-left above the deploy bar (above the unit panel if
open).

Other M10 hooks: `ui.bus` (`EventBus<UiEventMap>`): `screen {name}`, `runStart {city, game}`,
`runEnd {city, victory}`, `lowHate {hate, cheapest}` (Hate below the cheapest unlocked unit for
6 s during a wave; re-arms at 3× cheapest), `levelUpShown {level, unit}`. Game events stay on
`game.bus` (`ui.game`). Tutorial pointers: `ui.hud.deploy.cardRect(unit)`,
`ui.hud.wave.rect()`, `ui.hud.top.hateTarget` (UI px; × `ui.k` = device px). Toasts:
`ui.toast.info(text)`, `ui.moments.alert(kind, title, line, icon)`. Settings for the tutorial:
`ui.settings.replayTutorial` (Settings → TUTORIAL REPLAY) and `ui.settings.tutorialDone[city]`;
persist with `ui.saveSettings()`.

## 6. Responsive rules

`computeHudLayout(W, H, safe, {touch, minimap})` (unit-tested at all five target viewports):
top bar 1 row ≥ 440 UI px wide else 2; compact cards when H < 280 or W < 300; deploy bar
centred, scrollable when 11 cards don't fit; minimap bottom-right beside the bar when there is
room, else top-right under the bar (phones: 72-px frame + toggle); on phones the top + deploy
bars cover ≤ 25 % of the screen and cards stay ≥ 44 CSS px tall. Safe-area insets come from a
probe element (`env(safe-area-inset-*)`) and pad the bars, menus and alerts.

## 7. Debug params (additions — all M8 params still work)

| Param                  | Effect                                                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| _(none)_               | title screen; `?city=madrid\|london\|paris` or `?skipTitle=1` → straight into a run                                         |
| `screen=title\|select` | force a menu screen                                                                                                         |
| `moment=NAME`          | once ready: `levelup advisor threat breta prophets capitol wave alerts select deploy preview pause settings victory defeat` |
| `legit=N`              | Legitimacy inside `?level` (e.g. just below the next threshold)                                                             |
| `hud=0`                | hide the HUD (world-only shots)                                                                                             |

Shots: `node tools/shoot.mjs --page game --query "city=paris&autoplay=1&t=60&level=7&hate=800&wave=8&focus=crowd&moment=victory" --wait 30000`
(UI animations run on real time; SwiftShader at 3× DPR renders only a few fps — use long
`--wait`s for end screens on phones). `node tools/smoke.mjs` covers HUD click-through, card →
deploy, hotkeys, Space, Esc menu, title → select, touch card taps.

## 8. Notes / known issues

- `tests/balance-curves`, `sim-*` failures at the time of writing come from M12's in-progress
  data/sim tuning (parallel), not from M9.
- The Legitimacy seal digits and the kit card's `♥300` crowding are M5 art.
- The `+` glyph of the small font reads as a dot at small sizes ("CALL EARLY +7").
- The attract game uses `lean` art; far ground streams in a few seconds after the title shows.
- Strings live in `src/ui/strings.ts` until M10 moves them.
