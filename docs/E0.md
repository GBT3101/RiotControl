# E0 — City template (read this before E2–E5)

Phase 2 adds nine cities: `budapest`, `berlin`, `stockholm`, `vienna`, `amsterdam`, `rome`,
`barcelona`, `prague`, `milan` (PLAN §8). E0 made the codebase ready for them: every per-city
concern now reads **one module per city** from its own `cities/` folder, and each folder has an
index file where a city is added with **exactly one line**. Nothing else in the shared code needs
to change to add a city.

```
                       one file (or folder) per city                       + one line in
E2 blueprint           src/maps/cities/<city>.ts                             src/maps/cities/index.ts
E3 environment style   src/art/env/cities/<city>.ts (+ <city>.grid.ts)       src/art/env/cities/index.ts
E3 city vehicles       src/art/vehicles/cities/<city>.ts         (optional)  src/art/vehicles/cities/index.ts
E4 Capitol + landmarks src/art/landmarks/<city>/index.ts (+ builders)        src/art/landmarks/cities.ts
E5 music               src/audio/music/cities/<city>.ts                      src/audio/music/cities/index.ts
E5 copy                src/ui/text/city/<city>.ts                            src/ui/text/city/index.ts
```

The line is always the same shape, with the module exporting a const named after the city id:

```ts
export { budapest } from './budapest';
```

Re-read the index right before you add your line (other agents add theirs to the same file) and
keep the canonical city order of `CITIES` (src/maps/contract.ts) if you can; the registries sort
by `CITIES` anyway (`cityTable`, src/maps/cityTable.ts), and they throw at import time on an
export that is not a city id.

## 1. Playable vs. under construction

- **A city is playable once its blueprint line is in `src/maps/cities/index.ts`.**
  `PLAYABLE_CITIES`, `isPlayable(id)` and `playableOr(id, fallback = 'madrid')` live in
  `src/maps` (index.ts). `CITIES` / `CityId` list all 12 known ids; only playable ones may be
  loaded.
- Nothing at runtime reaches an unbuilt city: `loadMap` throws for it; the city select lists
  `PLAYABLE_CITIES` (the Europe map, E1, should grey out every pin with `!isPlayable(id)`); `UiApp.startRun` and the app's initial city go through `playableOr`
  (`?city=<unbuilt>` boots Madrid); saved settings drop a non-playable `lastCity`; records keep a
  zeroed record for every id (no migration needed when a city ships); `node tools/playtest.mjs`
  and `node tools/soak.mjs` default to every playable city and exit 2 on an unbuilt one
  (tools/lib/cities.mjs); the map viewer and the audio dev page list only cities that exist.
- **Stand-ins.** While a playable city is missing a piece, the game borrows Madrid's (env style,
  Capitol art, step stone, copy under the city's own name; props resolve to `prop.*.madrid`;
  music falls back to the Ministry's) so the blueprint author can already walk the city in game.
  Missing secondary-landmark art is simply not drawn.
- **`tests/cities-complete.test.ts` fails CI** for every playable city that lacks its own env
  style, Capitol art at the contract footprint, flags, art for each landmark it places, music,
  copy (masthead + sign slogans that render in the sign font), existing parked-car ids, an
  existing protest item, a registered graffiti tag, or a prop for any decor kind it places. So
  E2's blueprint line and the E3/E4/E5 pieces of a city must land together (the orchestrator
  merges them as one set). The same file checks that unbuilt ids cannot be loaded, picked or
  remembered.

## 2. Contract (src/maps/contract.ts)

`CityId`/`CITIES` list the 12 cities (Madrid, London, Paris first: their art, atlases and saves
are unchanged). `CAPITOL_FOOTPRINT` and `LANDMARKS` are fixed so blueprints (E2) and art (E4)
agree. Capitol footprints are PLAN §8.2's. Landmark footprints were chosen from the real
monuments' proportions at the game's scale — roughly 10–20 m per tile, monuments slightly
inflated for readability, matching the existing set (Puerta de Alcalá 4×2 for a 36 m gate,
Westminster Abbey 7×4, Buckingham 10×5, Orsay 10×5 for 188 m, Eiffel 6×6, Nelson 2×2 for a column,
statues 1×1). `w` runs along i, `d` along j; the long side is `w` so the main face can front a
+j street, as for the Capitols.

## 3. E2 — blueprint (`src/maps/cities/<city>.ts`)

Format and conventions: docs/M2.md and src/maps/blueprint.ts (`Blueprint`). Copy the shape of
`madrid.ts`: `export const budapest: Blueprint = { city: 'budapest', name: 'Budapest', … }`.
The Capitol uses `CAPITOL_FOOTPRINT.budapest`; place only your city's `LANDMARKS`.
`style.sidewalkProps` / `plazaProps` / `decor` kinds resolve through `propSprite` (shared kinds
in `PROP_KINDS`, src/art/env/props.ts; unknown kinds fall back via `PROP_FALLBACK` or come from
the city's own `props.extra`, E3). Spawn-district names are your copy.

Then add `export { budapest } from './budapest';` to src/maps/cities/index.ts — this makes the
city playable. Optionally add the city's key real streets to `REQUIRED_STREETS` in
tests/maps-blueprints.test.ts (a few lines of your own).

## 4. E3 — environment style (`src/art/env/cities/<city>.ts`)

Export `const <city>: EnvCity` (src/art/env/style.ts documents every field); pixel grids go in
`cities/<city>.grid.ts` (Prettier-ignored, hand-aligned). Madrid/London/Paris are complete
worked examples — copy one and replace everything. Fields:

| Field                                   | Used by                          | What                                                                                                                                                       |
| --------------------------------------- | -------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `ground: CityMats`                      | ground.ts                        | asphalt, kerbs, pavement/cobble/plaza tones + cell grids, grass, gravel, water, quay, bridge rail, lot, leaves, `ironRail`                                 |
| `awnings`, `look(kind, d)`              | bld/looks.ts                     | awning pairs; the per-building palette roll (wall material/colour, trim, frames, shutters, iron, door, roof `slope`, flat roof, quoins)                    |
| `facade`                                | bld/facade.ts                    | `floor()` storey programme, `upperBay()` / `groundBay()` painters (stamp your modules with `stampModule`, helpers in bld/kit.ts), `door`, `shop(d)`, flags |
| `roofs`                                 | bld/building.ts                  | terrace tiles, chimney style, dormers, mansard stacks, rooftop clutter, optional `slopeTex(look, rise)` for new roof materials (copper, glazed tiles)      |
| `props`                                 | props.ts                         | lamp/metro/bin/bollard grids + keys, bench, kiosk, bus stop, planter, café, flag cloth, hire bikes; `extra` = city-only props `prop.<kind>.<city>`         |
| `preview`                               | preview.ts                       | gallery street corner: 4 buildings, trees, seed, city icons                                                                                                |
| `sampleRoof`                            | index.ts                         | roof of the gallery building samples                                                                                                                       |
| `decals`                                | game/assets/jobs.ts              | graffiti word (`decal.tag.<tag>`, shared design or your `tagGrid`), rain puddles                                                                           |
| `cars`                                  | view/ambient.ts                  | parked decor-vehicle ids (repeat = weight)                                                                                                                 |
| `minimapRoof`, `postcardSky`, `mapTint` | minimap, city select, map viewer | small colour hints                                                                                                                                         |
| `protest`                               | art/protesters/variants.ts       | the protesters' city item (`item.<id>` in items.grid.ts) and how often woke protesters swing it                                                            |

Swatches are RIOT-64 names (`'ochre3'`, `C('rust2')`), never hex. The painters must not learn
your city id: if a hook is missing, prefer a new optional field in `style.ts` (tell the
orchestrator) over `city === …` branches in shared files.

City vehicles (trams, local taxis): `src/art/vehicles/cities/<city>.ts` exporting
`const <city>: readonly CivDef[]`, built with the kit exported from src/art/vehicles/civil.ts
(`hatch(colour)`, `sedan(colour, extras?, side?)`, `bus(BusSpec)`, `vespa(colour, rider)`,
`car(CarSpec)`, `boxVehicle(BoxSpec)`, `lightbar`, `sideDecals`, `burn`). Ids must be unique
(`tram_budapest`); they register as `veh.<id>.<drive|parked|burnt|flipped|burning>.<dir>` and
can then be listed in `cars`. Add the line to src/art/vehicles/cities/index.ts (leave its
`export {};`).

New protest items, glyphs or decal tags not covered by a hook live in shared files
(art/protesters/items.grid.ts, glyphs.ts) — coordinate through the orchestrator.

## 5. E4 — Capitol and landmarks (`src/art/landmarks/<city>/`)

`index.ts` exports `const <city>: LandmarkCity` (src/art/landmarks/registry.ts):

```ts
export const madrid: LandmarkCity = {
  capitol: { w: CONGRESO_W, d: CONGRESO_D, top: 122, build: buildCongreso }, // (state 0–4) → Build
  stepStone: R.granite, // Ramp5 of the Capitol's approach steps
  landmarks: LANDMARKS_MADRID, // { [landmarkId]: { top, frames, fps, side?, build(frame) } }
  flags: { es: SPAIN }, // lm.flag.es (+ .torn, .small), designs in <city>/flag.ts
  registerFx: undefined, // optional extra overlay sprites (London: Big Ben's hands)
};
```

Put the Capitol builder (`<city>/<capitol>.ts`, like madrid/congreso.ts), the landmark builders
(`<city>/landmarks.ts`), the flag (`<city>/flag.ts`, `FlagDef` from ../types: keys
r R y o b k w g K on a FLAG_W × h cloth) and anything else in your folder. Shared pieces:
engine/ (Scene, materials, kit), props.ts (statues, lions, lamps), shared.ts (plates, paving,
basins, jets, classical walls). City modules must not import `registry.ts`, `index.ts`,
`fx.ts` or `secondary.ts` at runtime (type-only imports are fine): those import the cities.
`capitol.w/d` must equal `CAPITOL_FOOTPRINT[city]`; overlays (flags, fire, smoke) reference
registered sprites; damage states 0–4 as in docs/art/M3b.md. Add the line to
src/art/landmarks/cities.ts. For review images add your city to `SPECS` in
tests/landmarks-preview.test.ts (`M3B_EXPORT=1 npx vitest run tests/landmarks-preview.test.ts`).

## 6. E5 — music and copy

**Music** `src/audio/music/cities/<city>.ts` exports `const <city>: CityMusic` (src/audio/music/kit.ts):
`hold` and `march` are `StyleSpec`s (meter, key, tempo range, form, chord sections + night
sections, lead/harmony/chord/bass instruments from instruments.ts `INST_IDS`, rhythm and cadence
vocabularies, drum part), `fanfare` is the victory lead. The vocabulary (chords `I … V7h`,
`R8/R12/R16`, bass patterns, `marchDrums`, `waltzDrums`, `hit`, `roll` …) is in kit.ts; city-only
drum parts live in your file (Madrid's castanets). Listen on `/audio.html` (the city list fills
itself) or render offline (src/audio/dev/offline.ts `renderMusic({ city })`).

**Copy** `src/ui/text/city/<city>.ts` exports `const <city>: CityCopy` (src/ui/text/cities.ts):
name, tagline (≤ 40), capitol, ≥ 3 victory and ≥ 3 defeat decks (≤ 96, two lines),
welcome, flavour lines (≤ 84), `masthead` {title, dateline, motto} for the end-screen paper,
and ≥ 6 `slogans` for protest signs (3×5 sign font, ~5 characters; accents map to base letters in
art/protesters/glyphs.ts — the completeness test fails on a missing glyph). Tone: PLAN §1.10.
tests/ui-tutorial-text.test.ts checks every city's copy limits.

## 8. How E0 was verified (no change to the original three cities)

- 2295 hashes compared before vs. after on isolated trees (the pre-E0 snapshot vs. the same
  snapshot + only E0's files): every registered sprite (frames, anchor, fps, tags, order — env
  tiles, building samples, previews, props, landmarks, flags, vehicles, UI, protesters), every art
  job's output per city (atlas pages, manifests, building/landmark/terrain data, desktop + lean
  mobile plans), `loadMap` for seeds 0 and 3, copy, slogans, mastheads, and every music style
  plus 160 generated bars per section and time of day: **0 differences**.
- Game screenshots (`?city=madrid|london|paris`, zoom 2 day and zoom 4 night, fixed camera,
  frozen) before vs. after: pixel-identical.
- The sim/art determinism tests and the full suite pass unchanged.
